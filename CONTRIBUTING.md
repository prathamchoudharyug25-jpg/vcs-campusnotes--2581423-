# Contributing to CampusNotes

Thank you for contributing to CampusNotes!

## How to Contribute

1. Write clear and useful notes. Use proper headings, simple explanations, and relevant examples to make notes easy for students to understand.
2. Follow Conventional Commit messages when making changes. Examples:
   - feat: add new notes
   - fix: correct topic errors
   - docs: update README
3. Before submitting a pull request, check spelling and formatting, review your changes, and verify that the notes or documentation are accurate and complete.

## Pull Request Guidelines

1. Create a separate branch for your changes.
2. Give your commits clear and meaningful messages.
3. Explain your changes in the pull request description.
4. Submit your pull request for review.
